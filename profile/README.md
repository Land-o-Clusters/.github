# Land O’ Clusters

Small, exacting instruments — and the coast they were built on.

**Not dashboards.** A dashboard shows you a number. An instrument tells you where the number
came from, and declines to show you one it can’t stand behind.

### What lives here

- **[Floati](https://github.com/Land-o-Clusters/floati)** — the fleet operating system for
  local coding agents. Any harness, any mix — one bus, one board, one set of receipts.
  macOS today. **Early public cut.**
- **[Puddle](https://github.com/Land-o-Clusters/puddle)** — a tiny municipal government for
  your AI tooling: usage, cost, context pressure, leaky sessions, and how much water it all
  theoretically drinks. Zero telemetry; every number shows its receipts. **Pre-release.**
- **[sleight](https://github.com/Land-o-Clusters/sleight)** — Claude Code drives your Mac apps
  in the background through the computer-use engine bundled with the ChatGPT desktop app, and
  your cursor stays yours. Its benchmark publishes every run, failures included. **Early,
  unofficial.**
- **RoleGauge** — a dated record of what employers post, and an honest read of what it can
  support. **In private development.**

### The standard every repository here is held to

- **A test is not trusted to pass until it has been seen to fail.**
- **Numbers carry their provenance** — measured, derived, or estimated, stated on the surface
  rather than buried in a doc.
- **The same input returns the same answer.** Determinism is enforced, not hoped for.
- **An absence states its reason.** Unknown renders as unknown, never as zero.

These are build gates in the repositories above, not intentions in this file.
