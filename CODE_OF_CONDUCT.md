# Code of conduct

Short version: **be decent, argue about the work, and take a "no" without escalating.**

This organization adopts the [Contributor Covenant, v2.1][cc] as its code of conduct. Rather than
restate it here, that's the text that applies — read it there.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Report conduct problems privately to the maintainer via the email on the
[GitHub profile](https://github.com/penguinspecz). Reports are handled privately. Enforcement is at
the maintainer's discretion and ranges from a warning to a permanent block.
